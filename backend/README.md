# Backend

This folder is a separate Node.js backend for the project.

## Start the backend

```bash
npm start
```

## Run in development mode

```bash
npm run dev
```

The backend runs on `http://localhost:4000` by default.

## Test routes

- `GET /`
- `GET /api/health`

## Project structure

- `server.js`: backend entry point
- `package.json`: backend scripts
